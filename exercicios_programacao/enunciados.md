# Exercícios de Programação em C

Este documento contém 30 exercícios práticos de programação em C, abrangendo desde conceitos básicos até tópicos mais avançados como ponteiros e matrizes. Cada exercício é projetado para reforçar o aprendizado e a aplicação dos conhecimentos adquiridos.

## Seção 1: Fundamentos e Variáveis

### Exercício 1: Olá Mundo!

Escreva um programa em C que imprima a mensagem "Olá, Mundo!" na tela.

### Exercício 2: Soma de Dois Números

Crie um programa que declare duas variáveis inteiras, atribua valores a elas e imprima a soma desses valores.

### Exercício 3: Entrada e Saída de Dados

Desenvolva um programa que solicite ao usuário que digite um número inteiro, leia esse número e o imprima na tela.

### Exercício 4: Tipos de Dados

Escreva um programa que declare variáveis dos tipos `int`, `float`, `double` e `char`. Atribua valores a elas e imprima o valor de cada variável, juntamente com seu tipo.

### Exercício 5: Conversão de Temperatura

Crie um programa que converta uma temperatura de Celsius para Fahrenheit. O programa deve solicitar a temperatura em Celsius ao usuário e exibir o resultado em Fahrenheit. A fórmula é: `F = (C * 9/5) + 32`.

## Seção 2: Operadores e Estruturas Condicionais

### Exercício 6: Operadores Aritméticos

Escreva um programa que solicite dois números inteiros ao usuário e exiba o resultado da soma, subtração, multiplicação, divisão e o resto da divisão entre eles.

### Exercício 7: Par ou Ímpar

Desenvolva um programa que solicite um número inteiro ao usuário e determine se ele é par ou ímpar.

### Exercício 8: Maior de Três Números

Crie um programa que leia três números inteiros e imprima o maior entre eles.

### Exercício 9: Verificação de Idade

Escreva um programa que solicite a idade do usuário e informe se ele é maior de idade (18 anos ou mais) ou menor de idade.

### Exercício 10: Calculadora Simples

Implemente uma calculadora simples que solicite dois números e uma operação (+, -, *, /) ao usuário. Em seguida, exiba o resultado da operação. Utilize `if-else if-else`.

## Seção 3: Estruturas de Repetição (Loops)

### Exercício 11: Contagem Progressiva (`for`)

Escreva um programa que utilize um loop `for` para imprimir os números de 1 a 10.

### Exercício 12: Contagem Regressiva (`while`)

Crie um programa que utilize um loop `while` para imprimir os números de 10 a 1.

### Exercício 13: Soma de Números Pares

Desenvolva um programa que calcule a soma dos números pares de 1 a 50, utilizando um loop `for`.

### Exercício 14: Média de Notas (`do-while`)

Escreva um programa que solicite ao usuário que digite notas (números reais) até que ele digite um valor negativo. Ao final, o programa deve exibir a média das notas digitadas. Utilize um loop `do-while`.

### Exercício 15: Tabuada

Crie um programa que solicite um número inteiro ao usuário e exiba a tabuada desse número de 1 a 10, utilizando um loop `for`.

## Seção 4: Arrays (Vetores)

### Exercício 16: Preencher e Imprimir Array

Escreva um programa que declare um array de 5 inteiros, preencha-o com valores lidos do teclado e, em seguida, imprima todos os elementos do array.

### Exercício 17: Maior Elemento do Array

Crie um programa que encontre e imprima o maior elemento de um array de 10 inteiros.

### Exercício 18: Soma dos Elementos do Array

Desenvolva um programa que calcule e imprima a soma de todos os elementos de um array de 7 números reais.

### Exercício 19: Busca em Array

Escreva um programa que declare um array de 6 inteiros e um número a ser buscado. O programa deve informar se o número está presente no array e em qual posição (índice).

### Exercício 20: Array Invertido

Crie um programa que declare um array de 5 inteiros, preencha-o e, em seguida, imprima os elementos na ordem inversa.

## Seção 5: Matrizes

### Exercício 21: Preencher e Imprimir Matriz

Escreva um programa que declare uma matriz 3x3 de inteiros, preencha-a com valores lidos do teclado e, em seguida, imprima a matriz formatada.

### Exercício 22: Soma dos Elementos da Matriz

Crie um programa que calcule e imprima a soma de todos os elementos de uma matriz 2x2 de inteiros.

### Exercício 23: Diagonal Principal

Desenvolva um programa que declare uma matriz 4x4 de inteiros, preencha-a e imprima apenas os elementos da diagonal principal.

### Exercício 24: Transposta de uma Matriz

Escreva um programa que declare uma matriz 2x3, preencha-a e, em seguida, crie e imprima sua matriz transposta (3x2).

### Exercício 25: Soma de Duas Matrizes

Crie um programa que declare duas matrizes 2x2, preencha-as e, em seguida, calcule e imprima a matriz resultante da soma das duas.

## Seção 6: Ponteiros e Endereço de Memória

### Exercício 26: Ponteiro Simples

Escreva um programa que declare uma variável inteira, um ponteiro para inteiro e atribua o endereço da variável ao ponteiro. Imprima o valor da variável usando a variável e usando o ponteiro.

### Exercício 27: Alterando Valor com Ponteiro

Crie um programa que declare uma variável inteira e um ponteiro para ela. Use o ponteiro para alterar o valor da variável e, em seguida, imprima o novo valor da variável.

### Exercício 28: Ponteiro para Array

Desenvolva um programa que declare um array de 3 inteiros e um ponteiro para o primeiro elemento do array. Use o ponteiro para percorrer o array e imprimir seus elementos.

### Exercício 29: Troca de Valores com Ponteiros (Função)

Escreva uma função que receba dois ponteiros para inteiros como argumento e troque os valores para os quais eles apontam. No programa principal, declare duas variáveis, chame a função e imprima os valores antes e depois da troca.

### Exercício 30: Alocação Dinâmica de Memória (Ponteiros)

Crie um programa que solicite ao usuário o tamanho de um array de inteiros. Use `malloc` para alocar dinamicamente memória para esse array, preencha-o com valores lidos do teclado, imprima os elementos e, em seguida, libere a memória alocada com `free`.
